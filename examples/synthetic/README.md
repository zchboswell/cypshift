# Synthetic Phase 0 fixture

This tiny fixture exists only to exercise `cypshift` in examples and CI. Every
identifier, assay context, and measurement value is invented. The structures
are simple illustrative SMILES selected to cover valid inputs, an invalid
input, multiple fragments, assigned and unassigned stereochemistry, and a
standardized duplicate. The fixture contains no OpenADMET or experimental
data and must not be used to infer biological performance.

The fixture files in this directory are dedicated to the public domain under
CC0-1.0 (`https://creativecommons.org/publicdomain/zero/1.0/`).
