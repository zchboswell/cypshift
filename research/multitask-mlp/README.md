# EXP-M1 isolated runtime

This directory contains the CPU-only deterministic research runtime for the
OpenADMET CYP 2026 G2-4 masked multitask experiment. It is not part of the
installable `cypshift` package and must not change the root dependency lock.

The governing contract is
`benchmarks/openadmet_cyp_2026/global_v2_m1_synthetic_contract.json`. The
formal two-root resource probe remains disabled until a separate signed,
reviewed, integrated source-binding claim names the exact implementation and
lock bytes. Bounded implementation smokes are API checks only and are not
resource or scientific evidence.
